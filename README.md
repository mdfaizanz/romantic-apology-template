# Romantic Apology Template 💕

A beautiful, interactive, and fully customizable **romantic apology website** to say sorry to your girlfriend in a playful, lovely, and heartfelt way.

## ✨ Features

- **Smooth animated sections** with romantic flow
- **Fully customizable** – Change texts, her name, and add your own photos easily and download the final card.
- **Interactive elements**:
  - Playful "No" button that runs away when clicked
  - Clickable emoji that becomes happier
  - Photo slider with your own uploaded images
  - Confetti explosion when she forgives you ❤️
- **Mobile-friendly** design
- **No backend required** – Pure HTML, CSS & JavaScript
- Ready to host on **GitHub Pages**, Netlify, Vercel, etc.

## 🛠️ Easy Customization

1. Open `index.html`
2. Edit the **Configuration** section at the top:

```javascript
const config = {
    herName: "Afia",                    // ← Change to her name
    yourName: "Zohan",                   // ← Your name
    heroTitle: "I'm Sorry, My Love...",
    heroText: "Every moment without you hurts...",
    poem: `Your custom poem here...`
};
